# Infrastructure as Code Templates

A collection of reusable infrastructure templates for common platform patterns.

## Purpose

Accelerate infrastructure deployment with proven, reusable templates.

## Template Categories

- **Compute**: EC2, ECS, EKS configurations
- **Networking**: VPC, load balancers, DNS
- **Storage**: S3, EBS, EFS setups
- **Security**: IAM roles, security groups
- **Monitoring**: CloudWatch, logging configurations

## Supported Providers

- AWS (primary)
- Azure (partial)
- GCP (partial)

## Usage

Each template is self-contained and documented. Customize variables to match your requirements.

## Benefits

- Faster infrastructure setup
- Consistent configurations
- Best practices built-in
- Version controlled infrastructure
